Readable systems usually decay by accretion, not explosion.

Watch for these failure modes:

- too many one-off overrides
- decorative components outranking useful text
- routes that stop telling you where they actually go
- docs that start mirroring marketing language

If the structure can still be scanned from plain text, it is probably holding.
